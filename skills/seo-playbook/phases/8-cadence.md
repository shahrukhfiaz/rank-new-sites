# Phase 8. Cadence

| When | Do |
| --- | --- |
| Each publishing day | Check the allowance; fact-check drafts on publish day; run the checks; publish; run the score loop on the new pages ([Phase 3](3-score-loop.md)); record in the ledger; re-submit the sitemap and ping IndexNow |
| Weekly | Search Console pull (position bands, the top-20 count, pages close to page 1); URL Inspection of new pages; tracker update; link work within the pace |
| Monthly | Refresh dated facts and data; publish new dataset versions; re-judge snippet and seasonal tests against their baselines; a full-site score loop ([Phase 3](3-score-loop.md)) |
| After a template change | The score loop on one page of each changed template: Lighthouse, axe, the responsive check, extraction and the claude-seo agents |
